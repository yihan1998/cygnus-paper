\subsection{Scheduling Policies in the Wild}
\label{sec:background-scheduling}

A \textit{scheduling policy} is an algorithm that decide which task to serve at every time in the system.
We can classify scheduling policies into four main categories based on two dimensions:
whether preemption is allowed, and how the next task to run is selected.
\begin{itemize}
    \item \textit{Non-preemptive and non-priority based} policies (e.g., First-Come-First-Serve (FCFS)) execute tasks in the order they arrive, without allowing preemption. In this paper, we do not consider temporal information such as task arrival time as a priority attribute, and thus FCFS is categorized as non-priority based.
    \item \textit{Non-preemptive and priority-based} policies (e.g., Shortest Job First (SJF)) select the next task to run based on a priority attribute such as expected service time, but do not allow preemption.
    \item \textit{Preemptive and non-priority based} policies (e.g., Processor Sharing (PS)) allow preemption, but do not use any priority attribute to select the next task to run. Instead, they typically use a round-robin approach to share the processor among all tasks.
    \item \textit{Preemptive and priority-based} policies (e.g., Shortest Remaining Processing Time (SRPT)) allow preemption and select the next task to run based on a priority attribute such as attained service time or expected remaining service time.
\end{itemize}

Formulating a non-preemptive scheduling policy is relatively straightforward, as it does not require the ability to interrupt a running task.

On the contrary, formulating a preemptive scheduling policy is more challenging, as rescheduling decisions might happen during the execution of a task.
We focus on three main categories of scheduling policies in this domain:
\begin{itemize}
    \item \textit{Size-based policies}, which prioritize tasks based on their expected service time, 
    \item \textit{Age-based policies}, which prioritize tasks based on their waiting time, and 
    \item \textit{Deadline-based policies}, which prioritize tasks based on their deadlines.
\end{itemize}

Prior work~\cite{scully2018soap} unified some of these policies under a common framework, showing that they can be expressed as a single \textit{rank} function that assigns a priority to each task based on its attributes such as task size and age.
