Modern cloud services, including web search, online retail, and serverless platforms, operate under microsecond-scale latency Service Level Objectives (SLOs) \cite{barroso2017attack,kaffes2019shinjuku,marty2019snap,zhang2021demikernel,iyer2023achieving}.

Prior works have demonstrated that preemptive scheduling is essential for meeting the latency SLOs of modern cloud services \cite{prekas2017zygos,kaffes2019shinjuku}.
They have also proposed various implementation of implementing preemption in user space at microsecond-scale \cite{prekas2017zygos,kaffes2019shinjuku,fried2020caladan,iyer2023achieving,lin2024fast}.

However, existing works tactically embrace a centralized dispatching model for preemption issuing.
While this model simplifies the design and implementation of preemptive scheduling, it also plant the seed of scalability as the number of cores growingly increases in Post Moore's Law era.

In this work, we address the scalability challenge with Cygnus, a new dataplane OS architecture.
Our key insight is that modern processors already provide hardware primitives, i.e., Memory Protection Keys (MPK) and the Local Advanced Programmable Interrupt Controller (LAPIC), to enable decentralized preemption.

Cygnus achieves decentralized preemption by following an Exokernel philosophy:
it exposes the timer subsystem directly to a per-core privileged \textit{Shadow Ring}, effectively a hardware-isolated Ring 1 component in userspace.
Cygnus relies on three key mechanisms to implement the Shadow Ring.
Firstly, Cygnus leverages MPK to isolate the Shadow Ring from untrusted applications running in Ring 3.
Secondly, Cygnus utilizes the LAPIC timer as the source of preemption, allowing each core to independently schedule its own preemption events.
Thirdly, Cygnus has Secure Upcall mechanism to securely transfer control from the application to the Shadow Ring upon preemption.
